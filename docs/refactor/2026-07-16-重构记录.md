# 2026-07-16 重构记录

## 数据结构决策：tuple / NamedTuple / dataclass 阶梯

定下新增类型选型的判据：

| 档                    | 适用                                                                         | 例子                                                                                    |
| --------------------- | ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| **plain tuple**       | 局部、≤2 字段、立刻解构、位置语义天然。或用作快照容器+可哈希。               | `LocateContext.children` 容器、`identify_headings` 的 `(headings, heading_styles)` 返回 |
| **NamedTuple**        | 要命名、无行为、纯数据记录。**本次未引入**（为与族内 frozen dataclass 统一） |                                                                                         |
| **frozen dataclass**  | 命名 + 行为 + 会演化 + 同型字段对调风险 + 要不可变。默认选择                 | `Para` / `Replacer` / `TextBlock` / `ExtractJob` / `ImageItem` / `ParagraphItem` …      |
| **mutable dataclass** | 真要原地改字段。（本次未涉及）                                               |                                                                                         |

让步项（按本性保留，非 dataclass）：

- **PageItem**（`pdf_extractor`）：瞬态 sort-key 捆，靠解构访问、`y` 是位置式 sort key，留 `tuple[float, str, Any]`
- **AssetsResult**（`assets.py`）：固定 4-key dict，动态 `result[cat]` 访问（`getattr` 反而丑），保留 `dict[str, list[str]]`

## template-write：Scanner 三大 dataclass 聚合（C/D/E）

### 新增类型

```python
@dataclass(frozen=True)
class _Para:       # 取代 (style, text) 位置元组，两字段同型 str→对调风险
    style: str
    text: str

@dataclass(frozen=True)
class _StyleStats: # 取代 style_counts + style_texts 不可分对
    counts: dict[str, int]
    texts: dict[str, list[str]]

@dataclass(frozen=True)
class _ScanResult: # 取代 collect_paragraphs 的 3 元组返回
    all_paras: list[Para]
    stats: StyleStats
```

### 签名变化

| 函数                       | 改前                                                 | 改后                                                    |
| -------------------------- | ---------------------------------------------------- | ------------------------------------------------------- |
| `collect_paragraphs`       | `-> tuple[_Paras, _StyleCounts, _StyleTexts]`        | `-> ScanResult`                                         |
| `identify_headings`        | `(all_paras, style_counts, style_texts)`             | `(scan)`                                                |
| `print_style_hints`        | `(heading_styles, style_counts, style_texts, total)` | `(heading_styles, stats, total)`                        |
| `_is_custom_heading_style` | `(style, style_counts, style_texts)`                 | `(style, stats)`                                        |
| `_is_caption_style`        | `(style, style_texts)`                               | `(style, stats)`                                        |
| `_count_total_headings`    | `(headings, style_to_depth: _StyleDepths, ...)`      | `(headings, style_to_depth: dict[str, int], ...)`       |
| 所有函数内迭代             | `for style, text in ...` / `headings[ptr][1]`        | `for p in ...: p.style / p.text` / `headings[ptr].text` |

### 类型别名清理

- **删除** `_StyleCounts`、`_StyleTexts`、`_StyleDepths`（前两者语义落进 `StyleStats` 字段名；`_StyleDepths` 只在打印阶段内部用，就地内联 `dict[str, int]`）
- **保留** `type _Paras = list[Para]`——嵌套复合类型 + 仍以松散参数外逃（`find_empty_sections`、`print_structure` 不收整个 scan）

### 不打包的

- `headings` + `heading_styles`：产出即分家，打包反成负担
- `headings` + `empty_set`：`empty_set` 是瞬态派生结果

### 调用点（`section_filler.scan_docx`）

```python
# 改前：3 items → identify 3 params → find 2 params → print_hints 4 params
all_paras, style_counts, style_texts = scanner.collect_paragraphs(body, qn)
headings, heading_styles = scanner.identify_headings(all_paras, style_counts, style_texts)
...

# 改后：1 scan → identify 1 param → print_hints 3 params
scan = scanner.collect_paragraphs(body, qn)
headings, heading_styles = scanner.identify_headings(scan)
...
scanner.print_style_hints(heading_styles, scan.stats, total)
```

## template-write：`Replacer` 去重 `_replace_all`（P1）

### 重复签名与重复代码

`content_map` + `pattern` 对在 `placeholder.py`（4 函数）和 `text_filler.py`（2 函数）重复传递，且 `_replace_all` 在两个模块中**逐字重复**。

### 方案：新建 Replacer

新建 leaf 模块 `fill_template/replacer.py`：

```python
@dataclass(frozen=True)
class Replacer:
    """占位符替换规格：名称映射 + 占位符正则（group(1) 捕获占位符名称）。"""
    content_map: dict[str, str]
    pattern: Pattern[str]

    def replace(self, text: str) -> str:
        def replacer(match: Match[str]) -> str:
            return self.content_map.get(match.group(1), match.group(0))
        return self.pattern.sub(replacer, text)
```

### 改动

| 文件                  | 改动                                                                                                                    |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 新`replacer.py`       | `Replacer` 定义                                                                                                         |
| `filler.py`           | 构造`Replacer(content_map, compile(...))` 下发给 `fill_docx`/`fill_text`                                                |
| `docx/placeholder.py` | `fill_docx`/`_fill_paragraph`/`_fill_table` 签名 `(..., replacer)`；删除 `_replace_all`，调用改 `replacer.replace(...)` |
| `text_filler.py`      | `fill_text` 签名 `(..., replacer)`；删除 `_replace_all`（重复代码），调用改 `replacer.replace(...)`                     |

## `LocateContext.children`：`list` → `tuple`（真快照 + 可哈希）

`@dataclass(frozen=True)` 只锁绑定、不锁内容。`children` 原为 `list`：

- `hash(ctx)` 抛 `TypeError`（list 不可哈希）
- 理论上有被 `append`/pop 改坏的风险（虽然当前代码没做）

改为 `tuple` 后真不可变 + 可哈希，读取代码（索引/`len`/透传）零改动。

| 文件                | 改动                                                                                     |
| ------------------- | ---------------------------------------------------------------------------------------- |
| `locator.py`        | `children: tuple[Any, ...]`；`refresh_body` 内 `tuple(new_body)`；docstring "子元素元组" |
| `section_filler.py` | `LocateContext(children=tuple(body), ...)`                                               |

## read_documents P2：`TextBlock` 取代 5-tuple 下标（P2）

### 下标访问与字段重排序

`pdf_extractor.py` 内部 `_TextBlock = list[tuple[5]]`（x0,y0,y1,text,font_h），全按 `b[3]`、`b[1]` 下标访问，且 `_merge_text_blocks` 做了字段重排序（输入 (x0,y0,…)→输出 (y0,x0,…)），同一个值在上下游索引不同，极易出错。

### 方案：TextBlock dataclass

```python
@dataclass(frozen=True)
class _TextBlock:
    x0: float; y0: float; y1: float; text: str; font_h: float
```

消除重排序（统一字段序），`b[3]`→`b.text`、`b[1]`→`b.x0`，merge 逻辑用 `prev.x0`/`prev.text` 等替换 `merged[-1][3]` 下标重建。

### `PageItem` 保留 tuple

`list[tuple[float, str, Any]]`（y, kind, payload）靠解构 `for _, kind, payload in items` 访问、`y` 本身就是 sort key、`payload` 自身是 tuple，dataclass 无实际收益——留 tuple。

## read_documents P3：`ExtractJob` 统一分发（P3）

### 签名不统一与 PDF 特判

所有 extractor 都是 `extract_X(filepath, assets_dir=None)`（10 个），PDF 多一个 `render_pages`，分发处需特判：

```python
if fp.suffix.lower() == '.pdf' and render_pages:
    return handler(fp, ad, render_pages=render_pages)
return handler(fp, ad)
```

### 方案：ExtractJob dataclass

```python
@dataclass(frozen=True)
class ExtractJob:
    """单文件提取作业：文件路径 + 资源目录 + 强制渲染页码（仅 PDF）。"""
    filepath: Path
    assets_dir: Path | None = None
    render_pages: list[int] | None = None
```

### 分发统一

```python
# 改前
ad = Path(assets_dir) if assets_dir else None
if fp.suffix.lower() == '.pdf' and render_pages:
    return handler(fp, ad, render_pages=render_pages)
return handler(fp, ad)

# 改后
job = ExtractJob(fp, Path(assets_dir) if assets_dir else None, render_pages)
return handler(job)   # 无特判，10 个 handler 统一签名 handler(job)
```

各 extractor 函数内部解包 `filepath, assets_dir = job.filepath, job.assets_dir`（PDF 多取 `render_pages = job.render_pages`），函数体其余不变。

### 改动文件（P3）

| 文件                           | 改动                                                                                  |
| ------------------------------ | ------------------------------------------------------------------------------------- |
| `extractors/common.py`         | 新增`ExtractJob` 定义 + docstring 调整                                                |
| `extractors/__init__.py`       | `extract_file` 构造 `ExtractJob`，统一 `handler(job)`，删 PDF 特判；`ExtractJob` 导入 |
| `extractors/docx_extractor.py` | `extract_doc`/`extract_docx`/`_extract_doc_com` 签名 `(job)`，解包或透传              |
| `extractors/pptx_extractor.py` | 同上                                                                                  |
| `extractors/xlsx_extractor.py` | 同上                                                                                  |
| `extractors/pdf_extractor.py`  | `extract_pdf` 签名 `(job)`，解包 3 字段；加 `ExtractJob` 导入                         |

## template-write P5：`Item` 标签联合替代 `dict[str, Any]`（P5）

### stringly-typed dict 跨文件

`sections: dict[str, list[dict[str, Any]]]` 横跨 md_parser → cli → section_filler → elements，用 `item.get("type")` / `item["path"]` / `item.get("runs")` 等 string key 访问。5 处文件、多处分发全部依赖字典字面键，既无类型安全也无 IDE 补全。

### 新类型

```python
@dataclass(frozen=True)
class Run:          # 行内文本片段
    text: str
    bold: bool = False
    italic: bool = False

@dataclass(frozen=True)
class ImageItem:    # 内嵌图片
    path: str
    width_inches: float | None = None

@dataclass(frozen=True)
class ParagraphItem: # 文本段落
    runs: list[Run]

type Item = ImageItem | ParagraphItem   # 标签联合：isinstance 分发
```

### 边界加载器（`items.py`）

```python
def item_from_dict(d: dict) -> Item:
    """从 JSON 字典构造 Item：旧格式 (text/bold) → 单 Run 的 ParagraphItem。"""
    if d.get("type") == "image":
        return ImageItem(path=d["path"], width_inches=d.get("width_inches"))
    if "runs" in d:
        return ParagraphItem(runs=[Run(...) for r in d["runs"]])
    # 旧格式兼容
    return ParagraphItem(runs=[Run(text=d.get("text",""), bold=bool(d.get("bold",False)))])
```

### 分发变化

```python
# 改前：string dispatch
if item.get("type") == "image": ...
else: ...    # 假定 paragraph

# 改后：isinstance dispatch
if isinstance(item, ImageItem): ...
else: ...    # ParagraphItem，类型检查器可 narrowing
```

### 改动文件（P5）

| 文件                     | 改动                                                                                                                                                                                                                                        |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 新`items.py`             | `Run`/`ImageItem`/`ParagraphItem` + `Item` 别名 + `item_from_dict`                                                                                                                                                                          |
| `md_parser.py`           | 删`from typing import Any`；`parse_sections_md` 返回 `dict[str, list[Item]]`；图片/段落直接构造 dataclass；`_parse_inline` 返回 `list[Run]`                                                                                                 |
| `cli.py`                 | JSON 路径加`item_from_dict` 转换；路径改写改为 `items[i] = ImageItem(path=..., width_inches=...)`（frozen 数据类不可原地改字段）                                                                                                            |
| `docx/section_filler.py` | `fill_docx_sections` 签名 `sections: dict[str, list[Item]]`；dry-run 计数 `isinstance(it, ImageItem)`；加 `ImageItem` 导入                                                                                                                  |

### P5 遗漏修复

`section_filler.py` dry-run 分支的 `it.get("type")` 未同步改为 `isinstance(it, ImageItem)`。类型检查器（Pylance/pyright）报 `属性 get 未知` 后修复，并补加 `ImageItem` 导入。
