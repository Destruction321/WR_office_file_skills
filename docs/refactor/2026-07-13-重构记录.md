## 代码质量改进

### 1. `ensure_import()` 安装安全性

- `CalledProcessError` 转为 `ImportError`，调用方 `except ImportError` 回退正常触发
- **方案**：去掉进程级 `timeout=180`，改用 pip 自带 `--no-input` + `--timeout 60`
- 大包不再被误杀

### 2. 第三方导入入口安全审查

- 所有 `ensure_import` 调用点检查过一遍
- `scan_docx` / `fill_docx_sections` 去掉 `try/except`（硬依赖，无回退路径）
- `_verify_filled` 保留 `try/except`（非关键步骤）
- 其余包裹的都是合理的（可选依赖 + 回退，或管道批量容错）

### 3. 删除所有 `# type: ignore` 注释

- `attr=str` overload 返回 `Any`，`Any` 不触发赋值/运算符/属性访问类型错误
- `docx_placeholder.py` / `assets.py` / `ole.py` / `pdf_extractor.py` / `pptx_extractor.py` / `docx_extractor.py` / `xlsx_extractor.py`

### 4. 消除 `from docx.*` 直接导入

- `docx_extractor.py` / `docx_section_filler.py` 中所有 `from docx.oxml.ns import qn` / `from docx.shared import Inches` 改为 `ensure_import` 的 dotted 路径方式
